# Memory Rewriter AI 🧠✨

**Rewrite your past. Reclaim your future.**

Memory Rewriter AI is a privacy-first, local-first application designed to help you reframe negative memories and thoughts using advanced AI. Built with a focus on Stoicism, CBT principles, and mental resilience, it runs entirely in your browser using WebLLM technology.

## 🌟 Key Features

*   **🔒 Privacy First**: All AI processing happens locally on your device. Your personal thoughts never leave your browser.
*   **🧠 Cognitive Reframing**: Instantly reframe negative thoughts into Stoic, Rational, Compassionate, or even Humorous perspectives.
*   **✨ Mind Shift Meditation**: Generate custom, 3-step guided meditations based on your current emotional state.
*   **🎮 Gamification**: Earn XP, unlock badges, and level up as you build your mental resilience streak.
*   **🎨 Premium UI**: A stunning, monochrome-aesthetic interface powered by framer-motion and three.js particles.
*   **📊 Insight & Analytics**: Track your mood patterns and cognitive distortions over time.

## 🛠️ Tech Stack

*   **Frontend**: React (Vite) + TypeScript
*   **Styling**: TailwindCSS + Vanilla CSS Variables
*   **AI Inference**: WebLLM (In-browser Local LLM) & Pollinations.ai (backup)
*   **Animations**: Framer Motion, React Three Fiber (Drei/Maath)
*   **Database**: Supabase (for syncing encrypted user history)

## 🚀 Getting Started

1.  **Clone the repository**
    ```bash
    git clone git@github.com:itzmeahammed/memory-rewrite-ai.git
    cd memory-rewrite-ai
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Run Development Server**
    ```bash
    npm run dev
    ```

4.  **Open in Browser**
    Navigate to `http://localhost:5173` to start rewriting your narrative.
